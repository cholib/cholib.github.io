축구 분석 사이트 **fls9.kr**에 애드센스 승인을 받는 프로젝트다. 승인이 나면 끝이므로 Projects에 둔다.

## 목표

- **언제**: 11월 중순 신청
- **기준**: 공개 글 30편 안팎(경기 분석 + 칼럼)

## 신청 전 점검표

### 사이트 기본

- [x] 내 도메인(fls9.kr) + HTTPS
- [x] 소개·문의·개인정보처리방침 페이지
- [x] 문의 메일 contact@fls9.kr (도메인 메일 전달)
- [x] 구글 서치콘솔·네이버 서치어드바이저 등록, 사이트맵·RSS 제출
- [x] 모바일에서 읽기 편한 화면(한글 줄바꿈, 표 가로 스크롤)
- [x] 모든 글에 대표 이미지

### 콘텐츠

- [ ] 공개 글 30편 안팎
- [x] 직접 만든 그림·표만 사용(남의 사진·그래픽 금지, 사진은 커먼즈 자유 라이선스)
- [x] 도박·베팅을 연상시키는 표현 자동 차단(글 저장 단계에서 금지어 검사)
- [x] 숫자는 확률과 해설로만 — '맞히는 글'이 아니라 '읽는 글'
- [x] 칼럼 연재: 스카우팅 리포트(화), 전술 이야기(목), 숫자로 보는 축구(수)

### 신청 직전

- [ ] 글 수·칼럼 수 최종 확인 (월요일 현황판)
- [ ] 깨진 링크·빈 페이지 점검
- [ ] ads.txt 준비

## 콘텐츠 원칙 — 왜 이렇게 정했나

- **확률은 쓰되 예측을 팔지 않는다.** 결론은 하나를 찍지 않고 세 가지 결과의 확률과 해석으로 쓴다. 적중률은 사이트에 내세우지 않는다.
- **도박·베팅 연상 단어는 아예 못 쓰게** 막았다. 사람이 실수로 넣어도 저장이 안 된다.
- **확인된 사실만.** 결장·부상은 현지 매체로 확인한 것만, 출처 링크 필수.
- **올린 글은 지우지 않는다.** 예상이 빗나가도 지우거나 숨기거나 '빗나감' 표시를 하지 않는다.

## 승인 뒤 계획

- '뉴스' 분류 열기: 하루 1~2편, 큰 소식(이적·부상·감독 교체)만. 내 말로 쓴 요약 + 출처 링크 + 폴스나인 숫자 해설. 번역 옮기기·보도 사진 금지.
- 카카오톡 공유 버튼
- 방문 통계(Cloudflare Web Analytics)
