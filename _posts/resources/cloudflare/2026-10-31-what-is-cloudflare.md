## 매일 쓰는데 정체를 모르는 회사

요즘 저는 축구 분석 사이트 fls9.kr을 운영하고 있습니다. 사이트를 만들면서 계속 마주친 이름이 하나 있습니다. 클라우드플레어(Cloudflare)입니다. 도메인을 연결할 때도, 사이트를 세상에 공개할 때도 이 회사 화면을 거쳤습니다.

그런데 솔직히 고백하면, 저는 이게 정확히 뭘 하는 회사인지 몰랐습니다. "뭔가 엄청난 기술 같은데…" 하는 느낌만 있었죠. 그래서 이번 글은 저처럼 감이 안 오는 분들을 위해 썼습니다. 중학생도 이해할 수 있게, 비유부터 차근차근 풀어 보겠습니다.

먼저 질문 하나. 여러분이 주소창에 사이트 주소를 치고 엔터를 누르면, 그 짧은 순간에 무슨 일이 일어날까요?

## 인터넷은 '주소 → 전화번호부 → 가게' 순서로 움직입니다

클라우드플레어를 이해하려면 인터넷에서 사이트가 열리는 과정부터 알아야 합니다. 피자 가게에 주문하는 일에 빗대어 보겠습니다.

1. **도메인 = 가게 이름.** fls9.kr, naver.com 같은 주소는 사람이 외우기 쉬운 가게 이름입니다.
2. **DNS = 전화번호부.** 컴퓨터는 이름이 아니라 숫자(IP 주소)로 연락합니다. 그래서 먼저 전화번호부에서 'fls9.kr의 번호는 몇 번?'을 찾습니다.
3. **서버 = 가게 본점.** 번호를 알아내면 그 본점에 전화를 걸어 '글 주세요' 하고 주문합니다. 본점은 글과 사진을 배달해 줍니다. 이것이 화면에 뜨는 페이지입니다.

여기서 문제가 세 가지 생깁니다. 본점이 멀리 있으면 배달이 느립니다. 장난 전화가 한꺼번에 수백만 통 오면 가게가 마비됩니다. 통화를 누군가 엿들을 수도 있습니다. 클라우드플레어는 바로 이 세 가지를 해결하는 회사입니다. 손님과 본점 사이에 끼어들어, 주문을 대신 받아 주는 거대한 중간 창구입니다.

손님의 주문은 본점이 아니라 클라우드플레어에 먼저 닿고, 편의점에 없는 것만 본점까지 갑니다.

## 하는 일 1: 전 세계에 '편의점'을 차려 둡니다 (CDN)

클라우드플레어의 첫 번째 무기는 **세계 335개 도시, 125개가 넘는 나라에 퍼져 있는 컴퓨터 기지**입니다(2026년 6월 기준). 서울에도 있고, 런던에도, 상파울루에도 있습니다.

피자 가게로 다시 비유해 보죠. 본점이 미국에 하나뿐이면, 한국 손님은 바다 건너까지 주문을 보내고 기다려야 합니다. 그런데 동네마다 편의점이 있고, 그 편의점에 인기 메뉴를 미리 놓아 뒀다면 어떨까요? 손님은 집 앞에서 바로 가져가면 됩니다.

- **CDN(콘텐츠 전송 네트워크)**: 이렇게 세계 곳곳에 편의점을 두는 방식을 말합니다.
- **캐시(cache)**: 편의점 진열대에 미리 올려 둔 복사본입니다. 사진, 글꼴, 한번 만든 페이지처럼 자주 바뀌지 않는 것들이 여기 들어갑니다.

그래서 본점(서버)은 덜 바빠지고, 손님은 더 빨리 페이지를 봅니다. 클라우드플레어 발표로는 인터넷 전체의 약 20%, 방문자가 많은 상위 1만 개 사이트 가운데 37%가 이 편의점망을 거칩니다. 우리가 하루에도 몇 번씩 모르는 사이에 이 회사를 쓰고 있는 셈입니다.

## 하는 일 2: 가게 앞을 지키는 경비원입니다

두 번째 무기는 **보안**입니다. 모든 주문이 편의점(클라우드플레어)을 먼저 거치니까, 문 앞에서 수상한 손님을 걸러낼 수 있습니다.

- **디도스(DDoS) 방어**: 디도스는 가짜 주문 전화를 한꺼번에 수백만 통 걸어 가게를 마비시키는 공격입니다. 클라우드플레어는 수백 개 도시의 기지가 나눠서 받아내고, 가짜 전화는 본점까지 보내지 않고 끊어 버립니다.
- **봇 걸러내기**: 사람인 척하는 자동 프로그램(봇)이 글을 통째로 훔쳐 가거나 로그인을 두드리는 것을 막습니다. 가끔 보이는 '사람인지 확인 중' 화면이 바로 이것입니다.
- **HTTPS 자물쇠**: 주소창의 자물쇠 표시는 손님과 가게 사이의 통화가 암호로 바뀌어 있다는 뜻입니다. 중간에서 누가 엿들어도 내용을 알 수 없습니다. 예전에는 이 자물쇠(SSL 인증서)를 돈 주고 사서 달아야 했는데, 클라우드플레어는 자동으로 달아 줍니다.

많은 회사가 이 경비원을 쓰는 이유가 여기 있습니다. 클라우드플레어에 따르면 포춘 500대 기업의 45%가 유료 고객입니다.

## 하는 일 3: 아예 가게를 통째로 맡아 줍니다

처음에는 '편의점 + 경비원'이었는데, 요즘 클라우드플레어는 본점 역할까지 해 줍니다. 내 컴퓨터나 서버가 없어도 사이트를 운영할 수 있다는 뜻입니다.

| 서비스 | 비유 | 하는 일 |
| --- | --- | --- |
| DNS | 전화번호부 관리 | 도메인을 어느 서버로 연결할지 적어 두는 곳. 전 세계 기지가 동시에 답해서 빠름 |
| Pages | 완성된 매장 대여 | 만든 웹사이트 파일을 올리면 곧바로 전 세계에 공개. GitHub에 올리면 자동으로 다시 공개 |
| Workers | 편의점 알바생 | 편의점에서 간단한 일을 바로 처리하는 작은 프로그램. 본점까지 가지 않아도 됨 |
| R2 | 창고 | 사진·파일을 보관하는 저장소 |
| 도메인 등록 | 가게 이름 등록소 | 도메인을 직접 사고 관리 |

개발자 입장에서 큰 매력은 가격입니다. 개인 사이트 정도는 무료 요금제로 충분합니다. Pages는 한 달에 500번까지 공개(빌드)할 수 있고, Workers는 하루 10만 번까지 무료로 실행됩니다. 2026년 6월 기준 740만 명이 넘는 개발자가 이 플랫폼을 쓰고 있습니다.

## 제 사이트 fls9.kr은 이렇게 움직입니다

축구 분석 사이트 fls9.kr은 서버를 한 대도 빌리지 않고, 월 사용료 0원으로 돌아갑니다. 돈을 낸 것은 도메인 이름뿐입니다.

1. **도메인은 가비아에서 샀습니다.** 가게 이름만 등록한 것입니다.
2. **전화번호부(DNS)는 클라우드플레어에 맡겼습니다.** 가비아 관리 화면에서 '네임서버'를 클라우드플레어가 알려 준 두 개 주소로 바꾸면 끝입니다.
3. **글은 GitHub에 올립니다.** 새 분석 글이 GitHub 저장소에 들어가면…
4. **Pages가 알아서 공개합니다.** 클라우드플레어가 저장소 변화를 알아채고, 몇 분 안에 새 사이트를 만들어 전 세계 편의점에 뿌립니다.
5. **자물쇠(HTTPS)와 보안은 자동입니다.** 제가 따로 설정한 것은 없습니다.

즉 제가 하는 일은 '글을 저장소에 넣는 것' 하나뿐입니다. 배달, 경비, 자물쇠는 클라우드플레어가 맡습니다. 더구나 저는 이 과정을 예약 작업으로 자동화해서, 정해진 시간이 되면 글이 저절로 올라갑니다.

## 나도 써 볼 수 있을까? 무료로 시작하는 순서

네, 이메일 하나면 시작할 수 있습니다. 난이도 순서로 소개합니다.

1. **가입하기**: cloudflare.com에서 무료(Free) 요금제로 계정을 만듭니다. 카드 등록은 필요 없습니다.
2. **내 첫 사이트 공개하기 (Pages)**: 직접 만든 HTML 파일을 끌어다 놓으면 '이름.pages.dev' 주소가 생깁니다. 도메인을 사지 않아도 됩니다. 동아리 소개 페이지, 포트폴리오로 딱 좋습니다.
3. **내 도메인 연결하기 (DNS)**: 도메인을 산 뒤 클라우드플레어에 '사이트 추가'를 하고, 도메인 판 곳에서 네임서버 두 줄을 바꿉니다. 반영에는 몇 분에서 하루까지 걸릴 수 있습니다.
4. **GitHub 자동 공개 켜기**: Pages에 GitHub 저장소를 연결하면, 파일을 고칠 때마다 사이트도 자동으로 바뀝니다.
5. **한 단계 더 (Workers)**: 방문자 수 세기, 간단한 문의 양식 처리처럼 '서버가 필요한 일'도 작은 코드로 해결할 수 있습니다.

처음에는 1번과 2번만 해 보세요. 내가 만든 페이지가 인터넷 주소를 갖게 되는 경험만으로도 인터넷이 어떻게 움직이는지 훨씬 잘 보입니다.

## 알아둘 점: 경비원이 쓰러지면 거리가 멈춥니다

좋은 점만 있는 건 아닙니다. 너무 많은 사이트가 한 회사에 기대고 있다는 것 자체가 약점이 될 수 있습니다.

2025년 11월 18일이 그런 날이었습니다. 한국 시간으로 저녁 8시 20분쯤부터 X(옛 트위터), ChatGPT, 스포티파이, 리그 오브 레전드 같은 유명 서비스가 한꺼번에 오류 화면을 띄웠습니다. 대부분 사이트가 최대 3시간가량 불안정했고, 완전히 복구된 건 약 6시간 뒤였습니다.

원인은 해킹이 아니었습니다. 내부 설정을 바꾸다가 봇을 걸러내는 프로그램의 설정 파일이 평소의 두 배로 커졌고, 이 파일을 읽던 프로그램이 한계를 넘어 멈췄습니다. 경비원 한 명의 실수가 수많은 가게의 문을 동시에 닫게 만든 셈입니다.

그래서 중요한 서비스를 운영하는 회사는 만일을 대비해 다른 회사를 예비로 두기도 합니다. 개인 블로그라면 '가끔 이런 일도 있다' 정도로 알고 있으면 충분합니다.

## 한 문장으로 정리하면

**클라우드플레어는 손님과 웹사이트 사이에 서서, 빠르게 배달하고(편의점), 나쁜 손님을 막고(경비원), 필요하면 가게까지 대신 운영해 주는 회사입니다.**

어렵게 느껴졌던 기술도 비유로 뜯어 보면 생각보다 단순합니다. 다음에 주소창에 엔터를 누를 때, 그 짧은 순간에 전화번호부와 편의점, 경비원이 분주히 움직이고 있다는 걸 떠올려 보세요.

### 용어 정리

| 용어 | 한 줄 비유 |
| --- | --- |
| 도메인 | 가게 이름 (fls9.kr) |
| IP 주소 | 가게 전화번호 (숫자) |
| DNS | 이름으로 번호를 찾는 전화번호부 |
| 서버 | 글과 사진을 내주는 본점 |
| CDN | 전 세계에 퍼진 편의점망 |
| 캐시 | 편의점 진열대의 복사본 |
| DDoS | 가짜 주문 전화 폭탄 |
| HTTPS / SSL | 통화를 암호로 바꾸는 자물쇠 |
| Pages | 파일만 올리면 되는 매장 대여 |
| Workers | 편의점에서 일하는 작은 프로그램 |
