폴스나인은 사람이 손대지 않아도 돌아가게 만들고 있다. 그 예약 작업들이 언제 무엇을 하는지 한눈에 보려고 정리했다. 작업이 바뀌면 이 표를 고친다.

## 예약 작업 표

| 언제 | 작업 | 하는 일 |
| --- | --- | --- |
| 매시 55분 | 저장소 자동 동기화 | 맥미니 저장소와 GitHub을 같은 상태로 맞춤 |
| 매일 15:00·09:05 | 예약 글 공개 (GitHub Actions) | 발행 시각이 지난 글이 있으면 사이트 재배포 |
| 매일 16:47 | 백업·점검 | 백업, 그날 작업 결과 확인, 사이트 열리는지 확인 |
| 경기 일정에 맞춰 | 경기 분석 글 | 데이터 수집 → 계산 → 현지 소식 → 본문 → 사이트 반영 |
| 월 08:47 | 주간 현황판 | 공개 글 수, 유튜브 구독자·시청 시간을 목표와 비교 |
| 월 20:07 | 스카우팅 리포트 작성 | 화요일 15:00 공개로 예약 |
| 수 20:07 | 전술 이야기 작성 | 목요일 15:00 공개로 예약 |
| 이적시장 매주 월 / 그 밖엔 매월 1일 | 한국 선수 이적 점검 | 확정된 이적만 목록에 반영 |

## 알림 원칙

- **문제가 있을 때만 알린다.** 정상이면 조용히 끝난다.
- 알림 문구는 항상 '폴스나인: '으로 시작한다. 휴대폰 푸시 + 대화 메시지.
- 맥미니가 꺼져 있거나 잠자고 있으면, 그 사실만 알리고 아무것도 바꾸지 않는다.

## 작업 방(대화) 다섯 개

일이 섞이지 않게 대화를 나눴다. 방마다 맡는 폴더가 있고, 커밋 메시지 앞에 방 머리표를 붙인다.

| 방 | 머리표 | 맡는 것 |
| --- | --- | --- |
| 🏟️ 사이트 | [사이트] | 사이트 코드·디자인, 칼럼 |
| 📊 경기 분석 | [분석] | 분석 코드·데이터·모델 |
| 🎬 유튜브 | [유튜브] | 영상 제작 |
| 📖 책·특집 | [책] | 책 원고·연재 |
| 🛰️ 관제실 | [관제] | 예약 작업, 공통 규칙, 현황판 |

- 남의 폴더를 고쳐야 하면 작은 수정만 하고 커밋 메시지에 이유를 적는다.

## 원칙

- **GitHub이 정본이다.** 작업 시작 전에 최신을 받고, 끝나면 바로 올린다. → [맥미니 ↔ GitHub 동기화에서 배운 것](/resources/github/mac-github-sync/)
- **작업 절차는 문서(RUNBOOK)에 적는다.** 예약 작업은 매번 새로 시작하므로, 문서를 읽고 그대로 따른다. 사용자 결정은 날짜와 함께 문서 맨 위에 쌓는다.
- **되돌릴 수 없는 일은 사람이 한다.** 글 삭제, 계정 로그인, 업로드 같은 일은 자동화하지 않는다.
- **보안**: 비밀번호·토큰은 작업이 읽거나 출력하지 않는다. 보안문자는 풀지 않고, 우회하려고 꼼수(무작위 지연 등)를 쓰지 않는다.
- **맥미니 용량이 작다.** 작업이 만든 주고받기용 압축 파일은 작업 끝에 지운다.
